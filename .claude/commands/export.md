# Export every register and its evidence

Use a new file. Reconcile record counts and store it privately. The format is documented, not a built-in restore command.

```bash
node scripts/documentation.mjs export --out="<new private path.json>"
```

Read the output before reporting success. Add `--json` when combining records. On an ambiguous name, list the candidates and let the operator select. Never send, publish, change equipment or handle credentials.
