# Weekly documentation review

Run these three reads, then write the review draft:

```bash
node scripts/documentation.mjs attention
node scripts/documentation.mjs coverage
node scripts/documentation.mjs review-queue
node scripts/documentation.mjs draft-weekly-review
```

Read the draft. Start with critical assets without a reviewed recovery procedure, failed checks and overdue owners. Name the responsible person and date from the records. Do not invent decisions or send the draft.
