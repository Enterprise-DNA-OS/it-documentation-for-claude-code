# Assign documentation follow-up

Asset is optional. Confirm the owner and due date; do not invent commitments.

```bash
node scripts/documentation.mjs add-task "<task>" --owner="<owner>" --due=YYYY-MM-DD --asset="<asset>" --actor="<operator>"
```

Read the output before reporting success. Add `--json` when combining records. On an ambiguous name, list the candidates and let the operator select. Never send, publish, change equipment or handle credentials.
