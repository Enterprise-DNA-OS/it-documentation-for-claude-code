# Why this desk has no front end

The operator asks a question, reads the database result and records evidence through the CLI. Read-only HTML makes the weekly review and handover easy to share after checking them. There is no browser service or form to maintain.

IT Glue also provides credential storage, a mobile app, access management, integration-driven discovery and collaboration. This base is the documentation register and evidence desk. It does not replace a credential vault, a network scanner, live synchronisation, mobile capture or a shared client portal. A graphical network map gives visual topology; this base gives recorded upstream relationships and transitive downstream impact as records. It only knows dependencies entered by the operator.

Enterprise DNA scopes the shared screens, authenticated access and connections needed for a custom installation. Keep credentials in your existing secure vault. The base is useful offline after installation for one operator reviewing equipment, procedures and dates. No third-party sign-in is required to use those workflows.
